# KCPrompt

Official repository for the paper "KCPrompt: Knowledge-Guided Surrogate Optimization for Feedback-Free Discrete Prompt Adaptation of Black-Box Language Models" (Cheng-Ru Wei, Wei-Chi Liang, Wei-Po Lee; National Sun Yat-sen University).

The source code, the task-specific knowledge graphs constructed from the task corpora, and the searched prompts that support the findings of the paper will be released in this repository upon acceptance of the manuscript.

The GLUE benchmark datasets used in the experiments are publicly available at https://gluebenchmark.com.
